# CORA.C — Portfolio

Cora Chen 的个人作品集。最新版本包含固定导航、中英双语内容、项目图库、三轴金属字母与粉色玻璃球交互。

纯静态 HTML/CSS/JavaScript，无需安装依赖。GitHub Pages 设置为 Deploy from a branch → main → / (root)。

- index.html：入口
- style.css：样式
- app.js：页面路由
- content.js / projects.js：内容与图库
- metal-shelf.js：独立金属架与 3D 字母组件
- letter-interactions.js：字母运动曲线
- assets/：网站图片
- vendor/：本地 Three.js 和字体（含授权信息）

图片使用相对路径，适配 GitHub Pages 的 /portfolio/ 子目录。
